# Plein Pas Cher: τιμές καυσίμων σε όλη τη Γαλλία

Site με όλα τα πρατήρια της Γαλλίας (και της Κορσικής και των υπερπόντιων νομών), ταξινομημένα από το φθηνότερο στο ακριβότερο. Γαλλικά, με κουμπί για ελληνικά.

- **Αρχική**: αναζήτηση οποιασδήποτε πόλης ή ταχυδρομικού κώδικα με προτάσεις καθώς γράφεις, «κοντά μου» με την τοποθεσία του κινητού, τα 10 φθηνότερα πρατήρια της Γαλλίας ανά καύσιμο, μέση τιμή ανά νομό.
- **Φίλτρα**: ανοιχτό τώρα, 24ωρο μηχάνημα κάρτας, χωρίς αυτοκινητόδρομους, υπηρεσίες (πλυντήριο, μαγαζί, τουαλέτα, αέρας, φόρτιση, φαγητό, ATM), πόσο πρόσφατη είναι η τιμή, ακτίνα, ταξινόμηση κατά τιμή/απόσταση/ενημέρωση. Ο browser θυμάται τις επιλογές.
- **Κάρτα πρατηρίου**: με ένα πάτημα ανοίγει και δείχνει όλες τις τιμές, το ωράριο της εβδομάδας, τις υπηρεσίες, και κουμπιά για Google Maps και Waze.
- **Μία σελίδα ανά νομό** (π.χ. `/departement/75-paris/`), με τίτλο και περιγραφή στα γαλλικά για να βγαίνει στο Google όταν κάποιος ψάχνει «prix carburant Paris».
- **Αυτόματη ενημέρωση κάθε 6 ώρες**, δωρεάν, μέσω GitHub.
- Χωρίς cookies και χωρίς παρακολούθηση, άρα δεν χρειάζεται banner cookies.

## Τι κάνει κάθε αρχείο

| Αρχείο | Τι κάνει |
|---|---|
| `config.json` | Όνομα site, domain, email επικοινωνίας. **Το μόνο αρχείο που θα αλλάξεις.** |
| `build.py` | Κατεβάζει τις τιμές, καθαρίζει τα λάθη και φτιάχνει όλο το site στον φάκελο `_site/` |
| `departements.py` | Οι 101 νομοί της Γαλλίας |
| `static/` | Εμφάνιση (`style.css`), λειτουργίες (`app.js`), μεταφράσεις (`i18n.js`), εικονίδιο |
| `.github/workflows/deploy.yml` | Χτίζει και δημοσιεύει το site κάθε 6 ώρες και σε κάθε αλλαγή |
| `.github/workflows/keepalive.yml` | Εμποδίζει το GitHub να σταματήσει τις αυτόματες ενημερώσεις μετά από 60 μέρες |

## Τι καθαρίζει το script

- Τιμές παλαιότερες από 7 μέρες.
- Λάθη πληκτρολόγησης (π.χ. 0,199 € ή 9,99 €): ό,τι απέχει πολύ από τη μέση τιμή.
- Πρατήρια κλεισμένα οριστικά και καύσιμα σε έλλειψη.
- Αν η πηγή φέρει λιγότερα από 1.000 πρατήρια (κάτι χάλασε), **δεν δημοσιεύει τίποτα** και το site μένει όπως ήταν. Ξαναδοκιμάζει 3 φορές πριν τα παρατήσει.

## Στήσιμο

### 1. GitHub (10 λεπτά)

1. Φτιάξε δωρεάν λογαριασμό στο github.com.
2. **New repository** → όνομα π.χ. `plein-pas-cher` → **Public** → **Create repository**.
3. **uploading an existing file** → σύρε μέσα όλο το περιεχόμενο του φακέλου, μαζί με τον `.github` (σε Mac: `Cmd + Shift + .` στο Finder για να φανεί) → **Commit changes**.
4. **Settings → Pages → Source: GitHub Actions**.
5. **Actions → Mise à jour du site → Run workflow**. Σε 2–3 λεπτά το site είναι ζωντανό στο `https://<username>.github.io/plein-pas-cher/`.

### 2. Domain

1. **Αγορά**: σε έναν registrar όπως OVHcloud ή Gandi (γαλλικές εταιρείες). Ένα `.fr` κάνει συνήθως κάτω από 15 € τον χρόνο και μπορεί να το πάρει κάθε κάτοικος της ΕΕ.
2. **Επιβεβαίωση στο GitHub** (προστατεύει από κλοπή του domain): φωτογραφία προφίλ → **Settings → Pages → Add a domain**, και ακολούθησε τις οδηγίες.
3. **Σύνδεση με το site**: στο repo **Settings → Pages → Custom domain** → γράψε π.χ. `pleinpascher.fr` → **Save**. Κάν' το **πριν** από το βήμα 4.
4. **DNS στον registrar**: πρόσθεσε αυτές τις εγγραφές:

   | Τύπος | Όνομα | Τιμή |
   |---|---|---|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | AAAA | @ | 2606:50c0:8000::153 |
   | AAAA | @ | 2606:50c0:8001::153 |
   | AAAA | @ | 2606:50c0:8002::153 |
   | AAAA | @ | 2606:50c0:8003::153 |
   | CNAME | www | `<username>.github.io` |

   Σβήσε τυχόν παλιές A/AAAA εγγραφές που έβαλε ο registrar για @.
5. Μετά από λίγες ώρες (ως 24), τσέκαρε **Enforce HTTPS** στο Settings → Pages.
6. Στο `config.json` βάλε `"site_url": "https://pleinpascher.fr"` και το email σου στο `contact_email`. Πάτα **Commit**. Το site ξαναχτίζεται μόνο του με σωστά links, `sitemap.xml` και τη σελίδα νομικών πληροφοριών συμπληρωμένη.

### 3. Google

Πρόσθεσε το domain στο [Google Search Console](https://search.google.com/search-console) και κάνε υποβολή του `https://<domain>/sitemap.xml`. Έτσι το Google θα βρει γρηγορότερα και τις 101 σελίδες νομών.

## Δοκιμή στο λάπτοπ

```bash
python3 build.py
cd _site && python3 -m http.server 8000   # άνοιξε http://localhost:8000
```

## Αν κάτι πάει στραβά

- **Το site γράφει «données anciennes»**: Actions → δες αν το τελευταίο τρέξιμο έχει κόκκινο Χ και πάτα το για το λάθος.
- **Τα links σπάνε στο `github.io/plein-pas-cher/`** πριν βάλεις domain: η σελίδα 404 θέλει domain για να δουλέψει. Οι υπόλοιπες σελίδες δουλεύουν κανονικά.

## Σημαντικό

- **Δεδομένα**: Licence Ouverte (Etalab). Επιτρέπεται ελεύθερη χρήση, και εμπορική, με αναφορά της πηγής. Το site την αναφέρει σε κάθε σελίδα.
- **GitHub Pages**: είναι για μη εμπορικά sites. Αν αργότερα βάλεις διαφημίσεις ή πουλάς κάτι, μεταφέρουμε το site σε άλλη δωρεάν φιλοξενία (π.χ. Cloudflare Pages) και αλλάζουμε τη σελίδα νομικών πληροφοριών.
